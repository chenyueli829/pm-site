02 指数增长的终点已在眼前
最令 Dario 惊讶的不是技术进展，而是公众对"指数增长即将结束"的严重缺乏认知。

Big Blob of Compute 假说 2017 至今未变

  • 原始计算能力
  • 数据数量
  • 数据质量和分布（必须足够广）
  • 训练时长
  • 无限可扩展的目标函数（预训练是一种，RL 是另一种）
  • 归一化/条件化（数值稳定性）

样本效率的独特类比

预训练介于"人类进化"和"即时学习"之间。大脑不是白板——天生就有进化来的先验；语言模型从随机权重开始，更像白板。

学习层级：进化 → 长期学习 → 短期学习 → 即时反应

泛化是关键：预训练从同人小说语料 → 通用网页爬虫才真正泛化；RL 也一样——从数学竞赛 → 编程 → 更广泛领域。

时间差问题：技术 1-2 年到天才级，但数万亿美元收入可能要 1-5 年才能实现。

06 当 AI 能做一切，经济会商品化吗？
  • Claude、GPT、Gemini 在编码风格和推理能力上有细微差异——不是某个模型在某个领域更好，而是风格差异
  • 如果 AI 能完成整个模型生产过程，这种能力会扩散到整个经济——不是 AI 模型商品化，是整个经济同时商品化
  • 地理不平等担忧：硅谷增长率 50%，其他地区可能没什么变化
  • API 模式比人们预期的持续更久——不是所有 token 价值相同，某些可能值数千万美元

Claude Code 为什么赢

Anthropic 内部数百名程序员每天用它，形成极快的产品反馈循环。不是自上而下的战略决策，而是内部工具自然溢出。

07 监管困境

Dario 立场

  • 具体的州级法律（如田纳西州）可能很荒谬
  • 更危险的是：禁止州级监管 10 年，却没有联邦监管计划
  • 10 年对 AI 发展来说是永恒

建议路径

  • 从透明度标准开始
  • 监控自主性风险 + 生物恐怖主义风险
  • 随风险升级逐步加码（如强制生物分类器）
基本哲学：放松 AI 健康益处的监管，同时大幅增加安全和安全立法。
08 全球秩序重塑
  • 发达国家 AI 福利分配：不太担心，市场机制会确保
  • 真正担忧：发展中国家——撒哈拉以南非洲、印度、拉美——市场不完善，技术难部署
  • 中国芯片出口管制：核心担忧是中国政府用 AI 压迫人民
  • 危险情景：美中都有"天才国度"，双方都认为有 90% 胜率 → 战争概率大幅上升
激进希望：专制制度可能被技术淘汰，正如工业化淘汰了封建制度。

Claude 宪法澄清

  • 不是规则列表，是原则框架
  • Claude 不是自主代理，是"大多数情况可纠正，有原则性硬限制"
  • 默认执行用户任务，但拒绝创建生物武器或伤害他人

11 对 AI PM 的启发
启发 01
"可验证 vs 不可验证"是产品设计的关键分水岭——先做可验证场景（代码、数据、流程自动化），再做不可验证场景。
启发 02
API 模式比想象中持久——不是因为技术，是因为始终有新的能力边界需要有人"贴近金属"去实验。
启发 03
经济扩散有时间差——技术到天才级 ≠ 产品到天才级，中间是 PM 的工作空间。
启发 04
决策速度是被低估的竞争优势——Dario 说关键决策两分钟，这背后是对领域的深度理解。
启发 05
"不是所有 token 价值相同"——定价逻辑从"按量计费"走向"按价值计费"，这是 AI 支付产品设计的起点。
