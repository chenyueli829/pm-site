# 产品研究资料 — 按品类分文件夹

单产品深度稿、体验报告等保存在 **`产品/<品类文件夹>/产品名.md`**。共 **8** 个品类（不超过 10 个）。

| 子文件夹 | 收录范围 |
|----------|----------|
| **通用助手/** | 对话型助手（ChatGPT、Claude、Gemini、Meta AI、Le Chat 等） |
| **搜索与研究/** | 答案引擎、研究工具、企业搜索（Perplexity、NotebookLM、You.com、Glean 等） |
| **编程与构建/** | IDE、编码代理、云端构建、**开发者 API / Console**、计算机使用类能力（Cursor、GitHub Copilot、Windsurf、Replit、Claude Code / Cowork、OpenAI Codex、OpenAI / Anthropic 平台与 Operator 等） |
| **工作与协作/** | 知识工作、办公生态嵌入（Notion AI、Microsoft Copilot 等） |
| **设计与内容/** | 图像生成、设计工具、演示内容（Midjourney、Adobe Firefly、Gamma 等） |
| **视频与数字人/** | 视频生成与数字人（Runway、Pika、HeyGen、Sora 等） |
| **语音与音频/** | TTS、语音产品（ElevenLabs 等） |
| **角色与陪伴/** | 角色聊天与陪伴（Character.AI 等） |

**共享资源**：体验报告截图等在 `产品/image/`（与各子文件夹并列）；报告内图片使用相对路径 `../image/...`。

**保存规则**：新建单品时先定品类，再写入对应子文件夹；若难以归类，优先并入语义最接近的一类，避免新增第 10 个以上品类文件夹（需改本说明与技能文档时再定新类）。

**深度稿体例**：与 `SKILL.zh-CN.md` **十四节深度研究卡片**对齐；章节清单与编号见 `../references/十四节深度稿结构.md`。历史稿件可能带「体例说明」blockquote 或中间节编号未完全顺排，以 **是否存在第十三节 Q&A 与第十四节具名对标** 为最低合规检查。

**例外**：文件名含 `产品体验报告` 的轻体验记录，遵循 **product-experience-report** 技能，可不采用十四节。
