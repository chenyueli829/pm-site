## 一、摘要

- 一句话定位：**AI 视频生成与数字人平台**，覆盖文本/脚本驱动成片、照片与虚拟人形象、口型同步、多语言配音与翻译、面向营销与培训的 **API**。
- 目标用户：出海营销、企业培训、销售与客服视频、创作者与 MCN、需批量多语言版本的视频团队。
- 核心工作流：选模板或 Agent -> 写脚本或上传素材 -> 选形象与声音 -> 生成与微调 -> 导出或走 API 批量管线。

---

## 二、为何重要

HeyGen 与 Synthesia、D-ID 等并列，体现 **「企业视频」品类**：买单理由常是 **降本、多语言、合规形象**，而不是单次炫酷生成。

**对 PM 的价值**：研究 **数字人 + 翻译 + API** 的三合一包装；B 端席位与 C 端积分的组合。

---

## 三、目标用户与场景（含痛点）

### 场景与痛点对照

| 用户场景 | 旧流程痛点 | 产品如何缓解 |
|----------|------------|--------------|
| 产品/广告短视频 | 实拍、演员、剪辑链条长；改一句口播要重录 | 数字人+脚本驱动快速改版，缩短 campaign 迭代 |
| 培训与合规多语种 | 每语种重拍或重配音，预算线性膨胀 | 翻译+配音+口型一站式，批量出多市场版本 |
| 销售个性化（若支持） | 大规模真人录制不可扩展 | 模板+变量或集成，降低「每人一条」边际成本 |
| API 集成 | 自研视频管线要接渲染、TTS、口型多家供应商 | 统一 API 与文档，把合规与计费交给平台层 |

## 四、核心工作流与交互模型

- **模板与 Studio**：非专业剪辑师友好，时间轴与口型/情绪参数产品化。
- **形象与声音资产库**：降低「找演员+录音棚」成本。
- **API / MCP（若提供）**：把能力接进自动化流水线。

## 十三、Product Q&A

| 问题 | 回答 |
|------|------|
| **用户第一次为什么来？** | 快速做带讲解的多语种视频而不用实拍。 |
| **用户第二次为什么回来？** | 系列内容与多市场版本要在同一风格下批量出。 |
| **解决了旧工作流中哪些痛点？** | 实拍贵、翻译重配音贵、剪辑门槛高。 |
| **核心护城河是什么？** | 形象与声音资产 + 企业客户 + API。 |
| **聊天工具 vs 任务完成工具？** | 任务完成工具（视频成片）。 |
| **AI 是主角还是嵌入工作流？** | AI 生成为主，嵌入营销/培训流。 |
| **产出可编辑/可验证/可分享/可复用？** | 可分享强；事实脚本需人工审核。 |
| **变现靠模型能力还是工作流价值？** | 分钟数/席位/API 等工作流与规模计费。 |
