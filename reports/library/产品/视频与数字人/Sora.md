## 一、摘要

- 一句话定位：OpenAI 的 **文/图驱动视频生成** 产品，将实验室视频模型包装为 **消费者可发布、可分享** 的创作体验，并与 **API / 平台能力** 在部分时期并行探索（具体以官方当前状态为准）。
- 目标用户：短视频创作者、营销与品牌、影视与广告前期、尝鲜型消费者。
- 核心工作流：输入提示或参考图 -> 选择时长与风格 -> 生成片段 -> 剪辑或重试 -> 导出发布。

---

## 二、为何重要

Sora 代表 **大厂的「视频作为消费产品」** 路径，与 Runway、Pika 等创企对照：资源投向 **模型、算力、版权与内容政策** 的平衡，而非单一功能点。

**对 PM 的价值**：研究 **C 端病毒传播 vs B 端 API 计量** 的取舍；内容与名人肖像等 **合规产品化**；以及官方 deprecation 时间表对 **API 客户** 的影响。

---

## 三、目标用户与场景（含痛点）

### 场景与痛点对照

| 用户场景 | 旧流程痛点 | 产品如何缓解 |
|----------|------------|--------------|
| 社媒短片 / 概念片 | 实拍与后期团队贵；创意窗口短 | 文本/图驱动快速出片，多版本试错 |
| 广告变体测试 | 每条素材单独拍摄不经济 | 低成本生成多风格小样做 A/B |
| 娱乐向视觉 | 传统 MV/特效门槛高 | 降低「有想法就能出画面」的技能壁垒（版权与肖像需合规） |

## 十一、风险、弱点与待验证

- 长视频叙事与一致角色仍是行业共性难点。
- **Deprecation**：视频 API 若调整，B 端客户需迁移计划——以 [OpenAI deprecations](https://platform.openai.com/docs/deprecations) 为准。
- 待验证：相对 Runway/Pika 的创作者忠诚度。

---

## 十二、PM 启示
### 12.1 PM 启示


- 视频是 **单位经济极差** 的品类，产品必须早期锁定 **高意愿付费场景**。
- 平台公司做消费视频，**政策与品牌风险** 权重高于小团队。
- API 与消费产品 **同能力不同合同** 时，路线图沟通是 B 端 PM 核心工作。
