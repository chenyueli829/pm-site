# 产品研究 — 本地研究资料库

本目录的完整路径为 **`{skill_root}/研究资料库/`**。**`{skill_root}`** 为技能包根目录：包含 **`SKILL.md`** 与 **`研究资料库/`**（通常与 **`SKILL.zh-CN.md`** 同级），可与 `.cursor/skills/…`、`~/.codex/skills/…` 等安装位置对应；**勿写死**具体绝对路径。

本目录用于**持久保存**结构化产品研究产出（PM 视角）。**规范条款以 `SKILL.zh-CN.md` 为唯一真源**；**`SKILL.md`** 为英文对照，路径与规则应与中文版一致。

**单品深度稿**须符合 **十四节结构**（摘要含三条链接与表、一至十四节标题、第十三节八问 Q&A、第十四节点名对标）。完整目录与旧稿迁移说明见 **`references/十四节深度稿结构.md`**。批量迁移可用 **`scripts/migrate_14_sections.py`**（路径相对技能根目录）。`*-产品体验报告-*.md` 等轻体验稿不必套用十四节。

## 研究主题与目录

| 目录 | 研究主题 | 用途 | 命名示例 |
|------|-----------|------|----------|
| **产品/** | **AI 软件 / 助手 / 工具等**（默认主题） | 单产品深度稿、Q&A、体验报告；**按品类子文件夹**（见 `产品/README.md`，共 **8** 个品类） | `产品/通用助手/ChatGPT.md`、`产品/搜索与研究/Perplexity.md` |

| **品类/** | **跨产品的对比与趋势**（文件名需可区分主题） | 对比矩阵、赛道总览 | `通用助手-对比矩阵.md`、`支付产品-对比矩阵.md` |
| **厂商/** | **同一公司多产品线 / 文档导航** | 调研清单、官方资源索引 | `OpenAI与Anthropic-产品调研清单.md` |

**新建主题：** 在本目录下新建**简短中文名**子文件夹（如 `企业服务/`）；若希望写入技能正文的主题表，在 **`SKILL.zh-CN.md`** 的 **「研究主题与资料库路径」** 中补充一行，或与用户约定后仅在实际使用时使用该文件夹。

## 命名与保存规则

- **单产品深度稿**：`产品/<品类>/产品名.md`；支付等主题用 `支付产品/产品名.md`。同一产品多次更新时**覆盖**或在文内更新「**最后更新：YYYY-MM-DD**」。品类见 `产品/README.md`。
- **品类文档**：默认 `品类/赛道或主题-类型.md`；跨主题须在文件名中体现。**与主题目录并存时：** 多品对照通常放 `品类/`；若对比对象**全部**属于某一主题（如支付）且单品已在 `支付产品/`，可将矩阵放在 **`支付产品/<细分>-对比矩阵.md`**，**避免**与 `品类/` 下**同范围**文件重复——**二选一**作为权威位置。
- **进度更新**：`更新/YYYY-MM-DD.md`；同日多次可**追加**；多主题并行时建议文件名带主题。更新已有稿件时，技能要求在外壳中写 **delta**（见 **`SKILL.zh-CN.md`**「周期性研究进度」）。
- **清单**：`清单/主题-类型.md`。

## 保存时的默认行为

- 用户只说「保存到研究资料库」且**未指定主题** → 默认 **`产品/`**（AI 软件主题）。
- 用户明确 **支付 / 计费 / 金融 / Midas** 等 → **`支付产品/`**（或已约定的其他主题目录）。

## 使用方式

- 「保存到研究资料库」「写入本地」等 → 产出写入本目录**对应主题子文件夹**，命名遵循上表。
- 增量更新按主题子目录进行；跨主题汇总放在 **`品类/`** 或单独索引，避免不同主题混在同一产品文件里。
